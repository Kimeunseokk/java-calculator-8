# java-calculator-precourse


## 문자열 덧셈 계산기
문자열 덧셈 계산기는 입력받은 문자열을 더하는 계산기로 기본구분자 :와 ,뿐만 아니라
특정 구분자 또한 입력의 범위로 허용하여 계산을 할 수 있는 계산기입니다.

## 기능 목록 
- 기본 구분자로 지정된 문자열의 숫자의 합을 구한다.
- 문자열이 //[구분자]\n형식일 경우 [구분자]를 커스텀 구분자로 지정하고 덧셈을    진행한다.  ex) "//;\n1;2;3" → 6
- 음수가 입력될 경우 예외를 발생시킨다.
- 잘못된 커스텀 구분자 형식이 들어오면 예외를 발생시킨다.
- 문자열에 숫자 이외의 값이 포함된 경우 예외를 발생시킨다.
- 정상 입력 시 모든 숫자의 합을 출력한다.
- 아무값도 입력되지 않았을때 예외를 발생시킨다.


## 예외 처리 규칙

| 상황 | 예외 메시지 |
|------|--------------|
| 잘못된 커스텀 구분자 형식 | `잘못된 커스텀 구분자가 입력되었습니다` |
| 숫자가 아닌 값 입력 | `숫자를 입력해주세요` |
| 음수 입력 | `음수는 허용되지 않습니다` |
